# Lab 3.2 Reflection

## Reflection

### 1. How did using Figma designs as references affect your coding process?

Using Figma gave me a clear visual reference for spacing, colors, sizing, and layout. It helped me compare my code to the design and make more accurate CSS choices.

### 2. What challenges did you encounter when aligning your code with the design specifications?

The biggest challenges were matching spacing, card size, font styles, image placement, and responsive behavior. Small differences in padding or font size could make the final result look noticeably different.

### 3. How can the feedback and community resources on Frontend Mentor help you improve as a developer?

Frontend Mentor feedback can help me notice mistakes I may not catch on my own. Seeing how other developers solve the same challenge can also give me new ideas for writing cleaner HTML and CSS.

## Summary

This lab helped me practice turning professional designs into working web pages using HTML and CSS. I also gained more experience with responsive layouts, Git commits, and matching design specifications.
